# FindPhone(スマホ探し)

同じWi-Fi内のPCから、なくしたスマホを最大音量で鳴らす。

## 使い方
1. GitHub Actionsの成果物から `FindPhone.apk` と `FindPhone.exe` を取得
2. スマホでアプリを開く(通知を許可・待受ONのまま)
3. 「ペアリングコードを表示」→ PCの「ペアリング設定」に入力(初回のみ)
4. 「音を選ぶ」で鳴らす音を選択(任意)
5. 「スマホを鳴らす」/「止める」

## セキュリティ
- 共有鍵(160bit乱数)を初回に手入力。以降の通信はすべてHMAC-SHA256で署名
- チャレンジ&レスポンス(1回限り・10秒有効)でリプレイ攻撃を防止
- LAN以外の送信元は無視。鍵はスマホ内部ストレージ/PCはDPAPIで暗号化保存
- コード画面はスクリーンショット禁止、画面を離れると自動で隠れる
- 鳴動は最大90秒で自動停止

## 署名鍵(任意)
未設定なら毎回debug署名(上書き更新不可)。固定したい場合はSecretsに
`KEYSTORE_BASE64` / `KS_PASS` / `KS_ALIAS` を登録。

## 通信
UDP 47321(スマホ側で待受)。
